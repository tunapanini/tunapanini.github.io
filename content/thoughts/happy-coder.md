최근 들어 자주 밤에 노트북 들고 카페에 가서 작업하다가 문 닫으면 나오곤 해요. 그리고 집에 갈 때 지하철에서 앉아서 폰 보며 'feature 추가 프로토타이핑 정도는 폰으로 원격이나 클라우드로 돌릴 수 있으면 좋을텐데...' 싶어서 찾아보고 있었거든요.

 
![[Pasted image 20250819200110.png]]

역시 개발자든 뭐든 사람 사는 건 다 똑같네요. 마침 해커뉴스에 [Happy - Claude Code Mobile Client](https://happy.engineering/)가 올라왔길래 써보고 있는데 느낌이 좋아요. CLI랑 앱이 기능/UX면에서 모두 상당히 이쁘고 깔끔합니다. 게다가 무료! 게다가 귀여움!


![[Pasted image 20250819203307.png]]

```sh
# Instead of claude, just run happy

happy
```

암호키로 로그인 하는 방식으로 암호화도 되고, relay 서버를 제공해서 따로 설정하지 않아도 네트워크 상관없이 연결도 간편해요. 한번에 다수의 머신에서 다수의 session을 한 번에 다룰 수 있어요. 작업 끝나면 푸시도 보내주고... 

실제로 외출하면서 한 번 써봤는데 생각보다 괜찮더라고요.

**새 기능 개발할 때:** 간단 내용으로 기획 문서 마크다운 작성 → 확인 후 수정 요청 -> 디자인 관련 결정사항 마크다운 작성 → 확인 후 프로토타입 개발 요청하는 식으로 단계별로 진행이 가능하고요. 시간이 5분 내외인 작업이 많아서 앱 끄고 딴 짓하다가 알림 받으면 확인하고 있어요.

**버그 픽스할 때:** 진행중인 작업 눈으로 따라가면서, 새로운 아이디어가 생기면 바로바로 던져줄 수 있어서 좋아요. 직접 디버깅도 못 하고 제약이 있지만, AI가 분석하려는 방향을 잡아줄 수도 있고 (아직 없었지만) 번뜩!! 하고 해결방안이 생각날 때 바로바로 수정하기 좋을 거 같아요.

**결론:** 아직 더 써봐야겠지만, 항상 켜둘 서버 하나만 있으면 잘 써먹을 수 있을 거 같아요. 나중에는 개발용으로 서버 머신을 따로 두고 밖에서 클라이언트만 써도 되지 않을까? 행복한 상상을 해봤습니다.
